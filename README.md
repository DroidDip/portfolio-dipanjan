# Dipanjan Chakraborty — Portfolio

A reference-faithful recreation of the visual language of the akaKimAnh portfolio, populated only with Dipanjan Chakraborty's resume content.

## Run locally
Open `index.html` directly, or serve the folder with any static HTTP server.

## GitHub Pages
Upload the contents of this folder to a repository and enable GitHub Pages from the repository's Pages settings.

## Included
- Responsive dark-first UI
- Floating glass pill navbar
- Spotlight cursor
- Grid background
- Animated role rotation
- Scroll reveal
- Project filters
- Command palette (⌘K / Ctrl+K)
- Resume download
- Accessible reduced-motion fallback


### Profile picture
Place your photo at `assets/profile.jpg`. The large DC holder automatically uses it when present and falls back to `DC` when absent.
